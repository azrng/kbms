# 微信动态表情包制作提示词（五步版）

> 用法：从第一步开始，**一次只发一步**的提示词给 AI，等它输出、你确认满意后再发下一步。
> 第一步提到的两篇外部教程可能失效，其核心制作方法已全部内嵌在文末附录，AI 照附录执行即可，无需访问任何链接。

---

## 第一步 · 总体要求（开工说明）

```
我想从 0 开始制作一套高质量的微信动态表情包，最后投稿到微信表情开放平台。

制作思路和操作方法以本文档附录《教程核心方法》为准（两篇参考教程的核心内容已整理在内，其中品牌周边、商品物料等不相关内容已剔除，不用研究）：
- 教程一：用即梦（Seedream）/豆包做动态表情包——角色设定表、四宫格出帧、四拍动作拆解、AI 质检、切帧脚本
- 教程二：用 ChatGPT Image 2.6 直出循环 GIF——定妆图参考、五段式提示词

我的要求：
- 采用尽量省手工操作、同时保证成品质量的制作方式
- 角色形象、主题、文案和最终效果由我确认，具体制作方案、工具调用、动画处理、GIF 合成及文件整理由你负责
- 请结合附录方法和当前可用工具，自行规划适合的制作流程，不需要我逐项指定技术实现方法
- 遇到需要我做选择的地方，记得让我确认
```

## 第二步 · 制作 IP 形象

> 发送前：把 `【填写喜欢的动物】` 换成你想要的动物，并**附上你目前的卡通头像图片**。

```
第二步：制作IP。我想设计一个专属的动物IP，后续用来制作微信动态表情包。我上传的是自己目前使用的卡通头像，请参考它的整体风格、气质和有辨识度的特征，帮我设计一只【填写喜欢的动物】。

希望新形象能让人联想到原来的头像，但不需要完全照搬人物的五官和造型。角色要保留动物原本的外形，不要强行拟人化。整体风格自然、可爱、有辨识度，适合后续制作不同情绪和动作的表情包。

请先生成角色形象供我确认，暂时不用制作动态表情。
```

**本步验收**：形象是否让你联想到原头像；动物特征是否保留（没被拟人化）；是否好认。不满意就指出具体问题（如"花纹太乱""颜色偏离头像"）让它改。**确认后保存这张图，它是整套表情的唯一角色标准。**

## 第三步 · 固定角色形象

> 发送时：**附上第二步最终确认的那张 IP 图**。

```
这张图片是最终确认的IP参考图。后续制作所有动态表情时，请保持角色的毛色、身体比例、五官、配饰和专属标志一致。可以根据文案改变动作和情绪，但不要随意修改角色的固定特征。
```

**本步验收**：AI 能复述出固定特征清单（毛色/比例/五官/配饰/专属标志）。建议让它主动列出这份清单，后续每张表情质检时逐项对照。

## 第四步 · 试做三张动态表情

> 发送时：**继续附 IP 参考图**。

```
现在用之前确认的形象，先制作三张微信动态表情：无语、还不发钱、不想干了。

按照前面学习的参考教程（附录《教程核心方法》），自行设计动作并制作成高质量动态GIF。要求：
- 保持角色形象一致：毛色、身体比例、五官、配饰、专属标志不变
- 动作自然、有表现力：按"预备→爆发→余波→回落"四拍设计，首尾帧衔接可无缝循环
- 文字使用我给出的原文，一字不差
- 每张 240×240，单文件不超过 500KB

做完先给我看效果，确认后再继续。
```

**本步验收**：三张是否同一只角色；文字零错字；动作是否表达出文案情绪；循环播放首尾是否跳变；文件是否达标（240×240、≤500KB）。这一步是试产，风格定调后第五步不再返工。

## 第五步 · 批量完成剩余表情

> 发送时：**附 IP 参考图**，把 `【粘贴剩余文案】` 换成完整文案列表。

```
前面制作的动态效果已经确认，继续按照这个风格完成剩余表情。文案如下：

【粘贴剩余文案】

每张结合文案设计不同的动作，保持角色形象和文字风格一致。做好后给我看效果，源图和GIF文件都保存好。
```

**本步验收**：逐张对照第三步的特征清单（同一只角色）；文字逐张核对零错字；源图（四宫格 PNG 或关键帧）与成品 GIF 都要归档保存，投稿微信表情开放平台时源文件还要用来做缩略图、封面、横幅、聊天面板图标。

## 附录 · 教程核心方法（AI 技术执行参考）

> 来自两篇教程的已验证做法，AI 在第二~五步执行时遵循本附录。

### A1. 产出规格（微信表情开放平台）

| 项目 | 要求 |
| --- | --- |
| 表情尺寸 | 240×240，GIF 格式 |
| 单文件 | ≤500KB |
| 套数量 | 16 张或 24 张 |
| 其他素材 | 缩略图、封面、详情横幅、聊天面板图标（投稿前以 sticker.weixin.qq.com《表情制作规范》《作品审核标准》最新版核对） |

### A2. 角色一致性（第二、三步用）

- **辨识锚点**：给角色定一个独特标记（缺角耳朵、挂件、一撮呆毛等），每张图的每一帧都必须清楚出现；判断角色崩没崩，先看锚点
- **固定特征清单**：毛色分布、花纹位置、眼睛颜色、脸型、身体比例、配饰、专属标志——第三步让 AI 列出，之后每张表情逐项对照
- **每张都回到参考图**：生成任何表情都要附带 IP 参考图，绝不链式引用上一张输出（误差会越积越大）
- 想锁色可让参考图带主色色块（主色≤4 种），质检时查配色跑偏

### A3. 动作设计四拍（第四、五步用）

每个表情拆 4 个关键帧：

1. **预备**：主动作前往反方向蓄力（要跳先蹲、要甩头先低头）
2. **爆发**：动作最夸张的一瞬间，表情拉到最大
3. **余波**：惯性带动耳朵、尾巴、配饰还在甩
4. **回落**：回到接近第 1 帧的姿态，保证循环首尾接得上

约束：
- 每张只做一个主动作（聊天窗口小，两个动作看不清）
- 只写画得出来的东西：肢体角度、眼睛形状、嘴型、道具位置；不写"可爱""生动"这类抽象词
- 每帧写明辨识锚点的位置
- 循环类表情让道具从开头就存在、结尾恢复开头姿态（如"开始时捧着道具，递出，收回，结尾恢复开头手势"）

### A4. 出帧方式（二选一，AI 按可用工具定）

**方式一 · 四宫格出帧（Seedream/即梦、可配合本地脚本）**

一张 2×2 四宫格出 4 个关键帧，同画布角色天然统一，生成次数省 3/4。提示词三把锁：

```
图1是IP参考图。按图1的角色画一张 2×2 四宫格，作为一个循环动图的 4 个关键帧。

身份锁：四格是同一个角色，外形、配色、比例和图1完全一致；【专属标志】四格都要清楚可见。
版式锁：四格大小相等，严格 2×2 排列，格子之间没有分隔线、边框和编号。四格角色脚底同一高度，身体居中，大小一致。
帧顺序：左上，右上，左下，右下。
第1帧：【预备：……】
第2帧：【爆发：……】
第3帧：【余波：……】
第4帧：【回落：……】
文字锁：四格顶部都写「【文案】」，粗圆体，黑字加白色粗描边，四格文字内容、位置、大小、字形完全相同。
背景：四格都是纯白色。
```

- 出图比例选 1:1；后期改字/改单格时**比例必须与原图一致**，否则四格重排
- 单格精修：只修崩掉的格，不整张重抽——`以图1为准，只修改【某格】，其他三格保持完全不变`；连带改动时在图上框出目标区域重发
- 切帧拼 GIF：脚本 `make_gif.py`（依赖 `pip3 install pillow`）：

```python
import sys, os, glob
from PIL import Image

SIZE = 240          # 微信表情尺寸
DELAY = 120         # 每帧停留毫秒数，越小越快
MAX_KB = 500        # 单个 GIF 大小上限

def grid_to_frames(path, rows=2, cols=2):
    im = Image.open(path).convert("RGBA")
    w, h = im.width // cols, im.height // rows
    frames = [im.crop((c * w, r * h, (c + 1) * w, (r + 1) * h)) for r in range(rows) for c in range(cols)]
    frames = [f.resize((SIZE, SIZE), Image.LANCZOS) for f in frames]
    return frames + frames[-2:0:-1]   # 1-2-3-4-3-2 来回帧

def save_gif(frames, out):
    for colors in (128, 64, 32):
        bg = Image.new("RGBA", (SIZE, SIZE), (255, 255, 255, 255))
        pal = [Image.alpha_composite(bg, f).convert("P", palette=Image.ADAPTIVE, colors=colors) for f in frames]
        pal[0].save(out, save_all=True, append_images=pal[1:], duration=DELAY, loop=0, optimize=True)
        kb = os.path.getsize(out) / 1024
        if kb <= MAX_KB:
            return kb, colors
    return kb, colors

os.makedirs("gif", exist_ok=True)
files = sys.argv[1:] or sorted(glob.glob("grids/*.png"))
for p in files:
    out = os.path.join("gif", os.path.splitext(os.path.basename(p))[0] + ".gif")
    kb, colors = save_gif(grid_to_frames(p), out)
    flag = "OK" if kb <= MAX_KB else "超标"
    print(f"{out}  {kb:.0f}KB  {colors}色  {flag}")
```

运行：`python3 make_gif.py`（单张重做 `python3 make_gif.py grids/07.png`）。超 500KB 自动按 128→64→32 色降级重试；速度调 `DELAY`（100 快 / 150 慢）。GIF 无半透明，动图一律垫白底，透明素材边缘才有毛刺。零代码备选：ezgif.com → Sprite sheet cutter（2×2 切帧）→ Delay 16 → Resize 240。

**方式二 · 直出 GIF（ChatGPT Image 2.6）**

上传 IP 参考图 + 五段式提示词：

```
【主体】保持参考图中的角色长相、毛色、配饰、专属标志完全不变
【风格】（例：扁平插画、Q 版 3D、水彩）
【动作】从 ___ 开始，到 ___ 结束
【循环】首尾衔接，无缝循环
【画面】正方形，背景 ___，镜头不动
```

- 必写【循环】和【镜头不动】：不写会自行加运镜、末帧跳回首帧
- 已实测：请求尺寸不一定兑现（写 1024 只给约 439px），下载后核对实际像素；2 秒/8 帧节奏最适合表情
- 小字易错字：文字放引号内、写明字体和"只出现一次"；仍失败就先出无字版，后期加字

### A5. 质检五项（每张交用户前 AI 自查）

1. **身份**：配色、花纹、五官、专属标志与参考图一致，无变化无消失
2. **位置**：各帧角色大小、脚底高度、左右位置一致（不一致动图会抖）
3. **文字**：与用户原文一字不差、位置一致、无错字
4. **版式**：无分隔线、边框、编号或多余元素
5. **循环**：末帧姿态能自然接回首帧

结论：通过 / 局部修（只修崩的格或帧）/ 重抽。

### A6. 红线

- 只用用户自己的头像和原创角色；明星、动漫角色、品牌形象一律不用（版权过不了审且涉诉）
- 文案不碰明星、影视、品牌、地域、政治；不照搬网络热梗原文（过时快、易撞车）
- 投稿素材（缩略图/封面/横幅/图标）以官方《表情制作规范》《作品审核标准》最新版为准
