本目录收录常用终端编码智能体及周边 AI 编码工具的使用笔记：Claude Code 与 Codex 各自独立成篇，pi、omp、Cursor、PAI 等其他终端智能体汇总在一处。内容涵盖安装、配置、常见问题解决与实用技巧，均为实际使用中沉淀的经验记录。

## 工具一览

| 工具 | 定位 | 适用场景 |
| --- | --- | --- |
| Claude Code | Anthropic 官方终端编码智能体 | 日常编码开发、网页界面设计、搭配状态栏与求职助手等扩展玩法 |
| Codex | OpenAI 官方终端编码智能体 | 终端内驱动编码任务，需处理 Windows 下中文乱码问题 |
| pi | 可通过扩展增强的终端智能体 | 按需叠加规划模式、记忆、网页访问、MCP、子代理等能力 |
| omp | 终端智能体，通过 `omp config` 管理配置 | Windows 终端使用，可配置主题、全局中文规范、关闭标题动画优化性能 |
| Cursor | AI 代码编辑器 | 关注 AI 生成 UI 质量的前端开发场景 |
| PAI | 个人 AI 基础设施框架 | 组织 AI 工具链、管理 prompt、让不同 AI 协作 |
