# 微信动态表情包制作提示词（自包含版）

> 用法：整体复制给 AI 助手即可开工。已将两篇教程的核心方法内嵌，无需再访问任何外部链接。

---

我想从 0 开始制作一套高质量的微信动态表情包，最后投稿到微信表情开放平台。请把下面这套已验证的流水线作为执行方案：角色形象、主题、文案和最终效果由我确认，其余制作、工具调用、动画处理、GIF 合成和文件整理全部由你负责。遇到需要我拍板的地方（角色方向、主题、文案定稿、最终验收）再来找我确认，其余步骤自主推进。

## 一、产出要求

- 一套 **16 张**动态表情：GIF 格式、240×240、单文件 **≤500KB**、可无缝循环
- 附投稿素材：缩略图、封面、详情横幅（以设定表为准出宽图，角色一侧留标题位）、聊天面板图标（用透明静态版直接出，不抠图）
- 全部表情基于**同一张角色设定表**生成，任何一步都不得凭空新画角色
- 文案不碰明星、影视、品牌、地域、政治；不照搬网络热梗原文

## 二、执行流程

### 第 1 步 · 角色设定表

先让用户确认角色：有照片（宠物/本人）就上传 2~4 个角度；没有就按用户给的人设原创。然后生成设定表：

```
画一张表情包角色设定表，作为后续所有表情的统一标准。

版式：横向画布。上排从左到右画三个全身像：正面、四分之三侧面、背面，三个等高、脚底对齐。下排画 4 个头部特写：大笑、生气、大哭、震惊。
角色：保留参考图中的【毛色分布、花纹位置、眼睛颜色、脸型】，Q 版，头身比约 1:1。
辨识锚点：【自选一个独特标记，如左耳缺角/挂工牌/一撮呆毛】，每一个视图里都必须清楚可见。
风格：粗黑描边，纯色填充，轻微阴影，主色不超过 4 种，画布右下角用 4 个小色块标出这 4 种主色。
背景：纯白，除色块外不要任何文字和标注。
```

- 设定表是整包的「定妆手册」：动作会转身低头，只有正面参考模型画侧面靠猜
- **辨识锚点**每帧必须出现，是判断角色崩没崩的最快依据；**色块**用来在质检时查配色跑偏
- 多抽几张挑一张存为 `sheet.png`；用户确认后锁定

### 第 2 步 · 选题（16 个聊天缺口）

请用户提供几段聊天记录（提醒删隐私），或让其描述聊天场景与说话风格：

```
请帮我找出 16 个聊天缺口：对话里我想表达态度，但打字太长、太正式、或不好意思直说的时刻。
每个缺口输出一行：场景 | 对方大概说了什么 | 我真实想表达的态度 | 能替我说出来的短句
要求：
1. 短句 2~5 个字，贴近用户口吻，可带嘴硬或自嘲
2. 覆盖接话类、情绪类、收尾类、拒绝类，拒绝类至少 3 个
3. 不照搬热梗原文；不涉及明星、影视、品牌、地域、政治
```

16 句文案列表交用户确认后锁定。

### 第 3 步 · 动作拆解（四拍动画）

把角色设定 + 16 句短句交给 AI 拆解成导演稿：

```
你是二维动画导演。请为每一句设计一个 4 帧循环的表演。
每一句按四拍设计：
第1帧 预备：主动作前往反方向蓄力（要跳先蹲、要甩头先低头）
第2帧 爆发：动作最夸张的一瞬间，表情拉到最大
第3帧 余波：惯性带动耳朵、尾巴、道具还在甩
第4帧 回落：回到接近第1帧的姿态，保证首尾接得上
要求：
1. 每句只做一个主动作（聊天窗口小，两个动作看不清）
2. 只写画得出来的东西：肢体角度、眼睛形状、嘴型、道具位置；不写"可爱""生动"
3. 每一帧写明辨识锚点的位置
输出表格：序号 | 短句 | 第1帧 | 第2帧 | 第3帧 | 第4帧
```

### 第 4 步 · 四宫格出帧（三把锁）

上传 sheet.png，每次取导演稿一行，生成 2×2 四宫格（**出图比例选 1:1**）：

```
图1是角色设定表。按图1的角色画一张 2×2 四宫格，作为一个循环动图的 4 个关键帧。

身份锁：四格是同一个角色，外形、配色、描边、比例和图1完全一致；【辨识锚点】四格都要清楚可见。
版式锁：四格大小相等，严格 2×2 排列，格子之间没有分隔线、边框和编号。四格角色脚底同一高度，身体居中，大小一致。
帧顺序：左上，右上，左下，右下。
第1帧：【预备：……】
第2帧：【爆发：……】
第3帧：【余波：……】
第4帧：【回落：……】
文字锁：四格顶部都写「【短句】」，粗圆体，黑字加白色粗描边，四格文字内容、位置、大小、字形完全相同。
背景：四格都是纯白色。
```

- 身份锁管不换脸；版式锁管动图不抖（脚本按等分切图）；文字锁管字不跳
- 需要静态表情/封面时：版式改单格，取第 2 帧
- 透明底必须写清**哪些区域**透明（只写"透明效果"会被理解成玻璃材质）；成品拖白/黑/红三底检查边缘
- 按序号存 `grids/01.png` … `grids/16.png`

### 第 5 步 · AI 质检（64 帧找茬）

把 sheet.png 和每张四宫格一起传给能看图的 AI：

```
图1是角色设定表，图2是一张四宫格动图帧。请逐格对照检查图2，只报告问题。
检查五项：
1. 身份：配色、花纹、眼睛、辨识锚点有没有变化或消失
2. 位置：四格角色大小、脚底高度、左右位置是否一致
3. 文字：是否一字不差、位置一致、无错字
4. 版式：有没有分隔线、边框、编号或多余元素
5. 循环：第4格姿态能否自然接回第1格
输出：格子位置 | 问题 | 处理方式（只修这一格 / 整张重抽）
结论：通过 / 局部修 / 重抽
```

### 第 6 步 · 单格精修

只修崩掉的格，不整张重抽。上传 grids 里的 PNG 原图，**出图比例必须与原图一致**：

```
以图1为准，只修改【某格】这一格，其他三格保持完全不变。
修改：该格里【具体改动】。
保持：该格其他内容、其余三格全部内容、顶部文字、纯白背景都不变。
```

若连带改动其他格，在图上框出目标区域重发。改完覆盖 grids 原图重跑脚本。

### 第 7 步 · 一键切帧拼 GIF

建目录：`mkdir -p 我的表情包/grids 我的表情包/gif 我的表情包/static`，脚本 `make_gif.py`：

```python
import sys, os, glob
from PIL import Image

SIZE = 240          # 微信表情尺寸
DELAY = 120         # 每帧停留毫秒数，越小越快
MAX_KB = 500        # 单个 GIF 大小上限

def grid_to_frames(path, rows=2, cols=2):
    im = Image.open(path).convert("RGBA")
    w, h = im.width // cols, im.height // rows
    frames = [im.crop((c * w, r * h, (c + 1) * w, (r + 1) * h)) for r in range(rows) for c in range(cols)]
    frames = [f.resize((SIZE, SIZE), Image.LANCZOS) for f in frames]
    return frames + frames[-2:0:-1]   # 1-2-3-4-3-2 来回帧

def save_gif(frames, out):
    for colors in (128, 64, 32):
        bg = Image.new("RGBA", (SIZE, SIZE), (255, 255, 255, 255))
        pal = [Image.alpha_composite(bg, f).convert("P", palette=Image.ADAPTIVE, colors=colors) for f in frames]
        pal[0].save(out, save_all=True, append_images=pal[1:], duration=DELAY, loop=0, optimize=True)
        kb = os.path.getsize(out) / 1024
        if kb <= MAX_KB:
            return kb, colors
    return kb, colors

os.makedirs("gif", exist_ok=True)
files = sys.argv[1:] or sorted(glob.glob("grids/*.png"))
for p in files:
    out = os.path.join("gif", os.path.splitext(os.path.basename(p))[0] + ".gif")
    kb, colors = save_gif(grid_to_frames(p), out)
    flag = "OK" if kb <= MAX_KB else "超标"
    print(f"{out}  {kb:.0f}KB  {colors}色  {flag}")
```

依赖：`pip3 install pillow`。运行 `python3 make_gif.py`（单张重做：`python3 make_gif.py grids/07.png`）。
GIF 无半透明，透明底边缘会毛刺，**动图一律垫白底**。零代码备选：ezgif.com → Sprite sheet cutter（2×2 切帧）→ Delay 16 → Resize 240。

## 三、验收红线

- 每张 GIF ≤500KB、240×240、首尾帧衔接自然（第 4 帧≈第 1 帧）
- 16 张放在一起是同一只角色：锚点、花纹、主色逐张核对
- 文字零错字；透明素材三底色检查边缘
- 投稿前以微信表情开放平台（sticker.weixin.qq.com）《表情制作规范》《作品审核标准》最新版为准核对尺寸与文件要求
- 只用用户自己的照片和原创角色；明星、动漫角色、品牌形象一律不用
