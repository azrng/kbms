## 高估值判断：500日均线 + 18% 标尺

### 为什么是 500 日均线

500 个交易日约等于两年。假设斜率平滑向上，这个均值大概率接近整个 500 天数据里价格的中位数，而中位数正好对应一年前——所以可以把 500 日均线当作**一年前价格的锚**。

不直接取前 250 天收盘价的原因：短期价格波动大容易失真；均值波动非常小，作为参照更准确。

### 18% 怎么来的

1. 历史统计：红利低波基金年化收益 12% 属正常（平均值），即一年后的合理价格 ≈ 价格锚 + 12%。
2. 真实走势不可能是一条无波动的斜线，所以按 12% 的倍数做参考：
   - **1.5 倍 = 18%**：价格提前透支了半年涨幅
   - **2 倍 = 24%**：价格提前透支了一年涨幅
3. 1.5 倍和 2 倍本身是「拍脑门」估算，不是科学精确值。因为波动率取决于当时的市场流动性和热度，无法精确预判。

### 历史回测验证

2023 年至今的 8 次山顶基本分布在当时 500 日均线 +28%~35% 的位置；近一年多的几个高点高出 500 日均线不多。具体高多少取决于当时市场环境和热度：2023、2024 年科技还在底部、红利如日中天时，涨得多些；红利行情低迷时高点自然低些。

### 使用原则

提前透支的涨幅最终要靠时间消化。若价格提前把明年 12% 都涨回来，宁可空仓等一年，闲钱放余额宝还能多赚点——价格一定会向合理价值回归。

## 止盈策略（分批止盈）

18%、24% 都不是精确值，意义在于给自己一个**止盈的大概标尺**。数据是死的，人是活的：

| 策略 | 触发点 | 特点 |
| ---- | ------ | ---- |
| 保守 | 收益 18% 以上开始分批卖出 | 大概率能吃到一部分，但也卖飞过 |
| 稍微激进 | 24% 以上再分段止盈 | 多吃肉就要多承担风险 |
| 过度贪婪 | 30% 才开始止盈 | 可能一直等不到，一直在电梯里上上下下 |

风险点：万一涨到 20% 就停车回落，谁也无法提前知道——18% 开始止盈的人已经卖了一部分，设太高的人还在等人接盘。

### 按持有收益百分比操作（财猫日记版）

:::tip

摘抄自：财猫日记（听不懂算我输版，适合长期投资者）

:::

看持有收益百分比，直接对应操作：

| 持有收益 | 操作 |
| -------- | ---- |
| 赚 2.5% 以上 | 别卖 |
| 赚 5% | 卖本金的 1/10（1 万卖 1000） |
| 赚 10% | 卖本金的 1/5（1 万卖 2000） |
| 赚 15% | 卖本金的 1/5 |
| 赚 20% | 卖本金的 1/4 |
| 赚 30% | 卖本金的 1/4 |

结论：交易没办法完美，也就不存在完美的方法，保证在正确的方向和逻辑里执行即可，不要过于执着。想明白后自己制定交易计划就行。

## 加仓判断（以红利低波50为例）

**追涨式加仓不可取**：6月不加仓、8月不加仓，看见涨了才大笔加仓，一旦亏钱就是罪过。

**性价比随价格递减**：以红利低波50为例，1.51 以下可以定投；短期价格再往上，性价比越来越低。同样风险下，原来押 10 块能赚 3 块，未来可能只赚 1 块——收益越来越鸡肋，但风险不降低甚至在升高。

**心态**：先改掉「看涨了就信心十足、勇者无畏」的习惯，再谈加仓。

## 红利指数 ETF 均线策略（普通人稳健版）

标的：红利指数 ETF/基金。核心规则：以 **250 日均线（年线）** 为基准。

| 价格位置 | 操作 |
| -------- | ---- |
| 低于 MA250 × 95% | 分批买入 |
| 等于 MA250 | 停止定投 |
| 高于 MA250 × 110% | 分批卖出 |

**股息率辅助判断**：

- 股息率 > 5%：可加大买入金额
- 股息率 < 3.5%：可提前全部卖出

**预期表现**：平均年化收益 9%~11%，最大回撤控制在 7% 以内，几乎没有大幅亏损风险。适合稳健理财的普通人，稳定盈利，大幅跑赢银行存款。

## 基金选择：只买行业 ETF 指数基金 / 宽指

:::tip

摘抄自：发牌手杰克

:::

对于基金产品只说一件事：**买且只能买行业类 ETF 指数基金 / 宽指**（举例说明，非推荐也非仅限于）：

- 行业类 ETF：医药 ETF、人工智能 ETF、恒生科技 ETF 之类
- 宽指：创业板 ETF、沪深 300、北交所指数、科创 50 之类

**最需要避开的 3 类**：

1. 混合类基金——「不三不四基金」
2. 基金经理很出名的品种——公关花了大价钱去宣传的
3. 名字听起来很牛的——本质上也是不三不四基金

**关键认知**：基金是否有行情，和净值高低无关，和是否新发售也无关，因为基金经理都是买股票作为标定的。（「净值便宜只有 0.8 几」不是买入理由。）

## 投资心态：破我执与破法执

- **知易行难**：先知后行需要过程。
- **术的层面**：学习投资理论、估值理论、交易技巧，能让人更客观地看待投资标的。
- **破我执**：不因主观情绪（如看涨就无畏）扭曲操作。
- **破法执**：投资最终是「从不为到无为」的过程，不执着于某一种方法论或估值法——它们只是工具，内心要有一套自己的判断。
